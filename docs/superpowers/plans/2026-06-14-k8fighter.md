**Goal:** A Street Fighter-style 1v1 web game where Kate fights Bungus (a fungal death-rabbit) — mid-depth combat (normals, blocking, throws, specials, super), best-of-3 rounds, reactive AI, three random stages, all-procedural art and audio.

## Shared conventions (read before any task)

These shapes and constants are created in Task 1 (`js/constants.js`) and used everywhere. Later tasks reference them — do not redefine.

**Globals (browser):** `FC` (constants), `Input`, `Fighter`, `Moves`, `Combat`, `Match`, `BungusAI`, `ArtKate`, `ArtBungus`, `ArtStages`, `ArtFX`, `Audio`, `Voice`. Each logic module also `module.exports` under node.

**Coordinate system:** virtual `FC.VW=960` × `FC.VH=540`. Floor line `FC.FLOOR_Y=470`. A fighter's `x` is the horizontal center of its pushbox; `y` is the feet contact line (equals FLOOR_Y when grounded, smaller when airborne). Up is −y. `facing` is `1` (faces right) or `-1` (faces left).

**Fixed timestep:** sim runs at `FC.FPS=60`, `FC.DT=1/60`. `main.js` accumulates real elapsed time and steps the sim in whole 1/60 increments (max 5 steps/frame to avoid spirals).

**Fighter object** (created by `Fighter.create`):
```
{ id, x, y, vx, vy, facing, onGround,
  state,        // 'idle'|'walkF'|'walkB'|'crouch'|'jump'|'block'|'blockLow'|'hitstun'|'blockstun'|'knockdown'|'attack'
  stateFrame,   // frames elapsed in current state
  move,         // moveKey string when state==='attack', else null
  hitThisMove,  // true once the current move has connected (so it hits once)
  health, meter,
  comboCount,
  hitstop }     // frames of freeze remaining (set on connect; decremented before sim)
```

**Numpad directions** (absolute, facing-independent): `7 8 9 / 4 5 6 / 1 2 3`, `5`=neutral. Derived from held arrows: up=8, down=2, left=4, right=6, and diagonals (e.g. down+right=3). `Input.dirFromKeys(keys)` returns this.

**Move object** (entries of `Moves.TABLE`):
```
{ key, startup, active, recovery,     // frame counts
  damage, hitstun, blockstun,
  hitKB, blockPush,                   // knockback / pushback px-per-frame impulse
  height,                             // 'high'|'mid'|'low'|'overhead'|'throw'
  knockdown,                          // bool
  meterGain, chip,                    // meter on hit; chip dmg on block (specials)
  cancelable,                         // can special-cancel on hit/block
  box,                               // hitbox {x,y,w,h} relative to fighter, facing-forward, feet-anchored
  hits }                             // optional multi-hit count (default 1)
```
Hitbox convention: `box.x` is forward distance from fighter center, `box.y` is height **above the feet** (so the actual top-left in world space is `y = f.y - box.y - box.h`), `w`/`h` size. `Combat.worldHitbox(f, box)` does the facing transform.

**Intent object** (per-frame, from `Input` or `BungusAI`), consumed by the orchestrator:
```
{ dir,          // numpad dir held this frame
  jump,         // edge: jump pressed this frame
  attack }      // null | { button:'A'|'S', heavy:bool, special:moveKey|null, throw:bool }
```

```js
// js/input.js — keyboard state + numpad/motion detection. Dual export.
(function (root) {
  'use strict';

  function dirFromKeys(k) {
    let x = (k.right ? 1 : 0) - (k.left ? 1 : 0);
    let y = (k.down ? 1 : 0) - (k.up ? 1 : 0);   // down is +1 (numpad bottom row)
    // numpad: 5 + x + (y * 3 inverted). Build explicitly.
    if (x === 0 && y === 0) return 5;
    if (x === 1 && y === 0) return 6;
    if (x === -1 && y === 0) return 4;
    if (x === 0 && y === 1) return 2;
    if (x === 0 && y === -1) return 8;
    if (x === 1 && y === 1) return 3;
    if (x === -1 && y === 1) return 1;
    if (x === 1 && y === -1) return 9;
    if (x === -1 && y === -1) return 7;
    return 5;
  }

  function mirrorDir(d) {
    const map = { 7: 9, 8: 8, 9: 7, 4: 6, 5: 5, 6: 4, 1: 3, 2: 2, 3: 1 };
    return map[d];
  }

  function createMotion() { return { hist: [] }; }

  function pushDir(ms, d, frame) {
    const last = ms.hist[ms.hist.length - 1];
    if (!last || last.d !== d) ms.hist.push({ d, f: frame });
    if (ms.hist.length > 18) ms.hist.shift();
  }

  // seq is defined facing-right; mirror it when facing === -1.
  function matchMotion(ms, seq, frame, bufferFrames, facing) {
    const want = facing === -1 ? seq.map(mirrorDir) : seq.slice();
    let si = want.length - 1;
    for (let i = ms.hist.length - 1; i >= 0 && si >= 0; i--) {
      if (frame - ms.hist[i].f > bufferFrames) break;
      if (ms.hist[i].d === want[si]) si--;
    }
    return si < 0;
  }

  // Browser key listener (no-op under node). Tracks held arrows + button edges.
  function attach(target) {
    const keys = {};
    const edges = {};            // one-shot pressed flags
    const MAP = {
      ArrowLeft: 'left', ArrowRight: 'right', ArrowUp: 'up', ArrowDown: 'down',
      KeyA: 'A', KeyS: 'S', Space: 'jump', Enter: 'enter', KeyH: 'help', Escape: 'esc',
    };
    const held = {};             // raw held timestamps for buttons (frames), set by consumer
    target.addEventListener('keydown', (e) => {
      const name = MAP[e.code]; if (!name) return;
      if (['left','right','up','down','jump','enter','help','esc'].includes(name)) e.preventDefault();
      if (!keys[name]) edges[name] = true;     // rising edge
      keys[name] = true;
    });
    target.addEventListener('keyup', (e) => {
      const name = MAP[e.code]; if (!name) return;
      keys[name] = false;
    });
    return {
      keys, edges,
      consumeEdge(name) { const v = !!edges[name]; edges[name] = false; return v; },
      arrows() { return { left: keys.left, right: keys.right, up: keys.up, down: keys.down }; },
    };
  }

  const API = { dirFromKeys, mirrorDir, createMotion, pushDir, matchMotion, attach };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.Input = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
// js/fighter.js — movement, gravity, facing, state timing. Dual export.
(function (root) {
  'use strict';
  const FC = (typeof module !== 'undefined') ? require('./constants.js') : root.FC;
  const Moves = (typeof module !== 'undefined') ? require('./moves.js') : root.Moves;

  function create(id, x, facing) {
    return {
      id, x, y: FC.FLOOR_Y, vx: 0, vy: 0, facing, onGround: true,
      state: 'idle', stateFrame: 0, move: null, hitThisMove: false,
      health: FC.MAX_HEALTH, meter: 0, comboCount: 0, hitstop: 0,
    };
  }

  function start(f, moveKey) {
    f.state = 'attack'; f.move = moveKey; f.stateFrame = 0; f.hitThisMove = false;
    f.vx = 0;
  }

  function applyHit(f, mv, fromX) {
    f.health = Math.max(0, f.health - mv.damage);
    f.state = mv.knockdown ? 'knockdown' : 'hitstun';
    f.stateFrame = 0; f.move = null;
    const dir = f.x < fromX ? -1 : 1;            // pushed away from attacker
    f.vx = dir * mv.hitKB;
    f.meter = Math.min(FC.MAX_METER, f.meter + Math.round(mv.meterGain / 2));
    if (mv.knockdown) { f.vy = -8; f.onGround = false; }
  }

  function applyBlock(f, mv, fromX) {
    if (mv.chip) f.health = Math.max(0, f.health - mv.chip);
    f.state = 'blockstun'; f.stateFrame = 0; f.move = null;
    const dir = f.x < fromX ? -1 : 1;
    f.vx = dir * mv.blockPush;
    f.meter = Math.min(FC.MAX_METER, f.meter + 1);
  }

  function maybeFaceOpponent(f, opp) {
    f.facing = (opp.x >= f.x) ? 1 : -1;
  }

  function step(f, intent, opp) {
    if (f.hitstop > 0) { f.hitstop--; return; }

    // timed states first
    if (f.state === 'attack') {
      const mv = Moves.TABLE[f.move];
      f.stateFrame++;
      f.vx *= 0.8;
      f.x += f.vx;
      if (f.stateFrame >= mv.startup + mv.active + mv.recovery) {
        f.state = 'idle'; f.move = null;
      }
      clampWall(f);
      return;
    }
    if (f.state === 'hitstun' || f.state === 'blockstun') {
      f.stateFrame++;
      f.vx *= 0.85; f.x += f.vx;
      const budget = f.state === 'hitstun' ? hitstunBudget(f) : blockstunBudget(f);
      if (f.stateFrame >= budget) { f.state = 'idle'; f.vx = 0; }
      clampWall(f);
      return;
    }
    if (f.state === 'knockdown') {
      f.stateFrame++;
      if (!f.onGround) { f.vy += FC.GRAVITY; f.y += f.vy; if (f.y >= FC.FLOOR_Y) { f.y = FC.FLOOR_Y; f.vy = 0; f.onGround = true; } }
      f.x += f.vx; f.vx *= 0.9;
      if (f.onGround && f.stateFrame >= 28) { f.state = 'idle'; f.vx = 0; }
      clampWall(f);
      return;
    }

    // airborne (jump) — locked to ballistic arc, no air control beyond initial
    if (!f.onGround) {
      f.vy += FC.GRAVITY; f.y += f.vy; f.x += f.vx;
      if (f.y >= FC.FLOOR_Y) { f.y = FC.FLOOR_Y; f.vy = 0; f.vx = 0; f.onGround = true; f.state = 'idle'; }
      clampWall(f);
      return;
    }

    // grounded neutral: facing, jump, crouch, walk, block
    maybeFaceOpponent(f, opp);
    const fwd = f.facing;                       // +1 toward right
    const toward = (intent.dir === 6 || intent.dir === 9 || intent.dir === 3) ? 1
                 : (intent.dir === 4 || intent.dir === 7 || intent.dir === 1) ? -1 : 0;
    const towardOpp = toward === fwd;           // pressing into opponent
    const awayOpp = toward === -fwd;
    const down = (intent.dir === 1 || intent.dir === 2 || intent.dir === 3);
    const up = (intent.dir === 7 || intent.dir === 8 || intent.dir === 9);

    if (intent.jump || up) {
      f.onGround = false; f.vy = FC.JUMP_VY;
      f.vx = towardOpp ? fwd * 4 : awayOpp ? -fwd * 4 : 0;
      f.state = 'jump'; f.stateFrame = 0;
      return;
    }
    if (down) { f.state = 'crouch'; f.stateFrame++; f.vx = 0; return; }
    if (awayOpp) { f.state = 'block'; }          // standing block when holding away
    if (towardOpp) {
      f.state = 'walkF'; f.x += fwd * FC.WALK_SPEED;
    } else if (awayOpp) {
      f.state = 'block'; f.x += -fwd * FC.BACK_SPEED;  // walk back = block-walk
    } else {
      f.state = 'idle';
    }
    f.stateFrame = (f.state === 'idle') ? f.stateFrame + 1 : 0;
    separate(f, opp);
    clampWall(f);
  }

  // crouch-block when holding down-away handled by combat (height check); here state stays 'crouch'.

  function hitstunBudget(f) { return f._stunBudget || 14; }
  function blockstunBudget(f) { return f._stunBudget || 9; }

  function clampWall(f) {
    if (f.x < FC.STAGE_LEFT) f.x = FC.STAGE_LEFT;
    if (f.x > FC.STAGE_RIGHT) f.x = FC.STAGE_RIGHT;
  }

  function separate(f, opp) {
    const dx = f.x - opp.x;
    const min = FC.PUSH_HALF_W * 2;
    if (Math.abs(dx) < min && opp.onGround && f.onGround) {
      const push = (min - Math.abs(dx)) / 2;
      const s = dx >= 0 ? 1 : -1;
      f.x += s * push;
    }
  }

  const API = { create, start, step, applyHit, applyBlock, maybeFaceOpponent };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.Fighter = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
// js/combat.js — hitbox/hurtbox resolution, blocking, throws. Pure. Dual export.
(function (root) {
  'use strict';
  const FC = (typeof module !== 'undefined') ? require('./constants.js') : root.FC;
  const Moves = (typeof module !== 'undefined') ? require('./moves.js') : root.Moves;
  const Fighter = (typeof module !== 'undefined') ? require('./fighter.js') : root.Fighter;

  function aabb(a, b) {
    return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
  }

  // world-space box from a facing-forward, feet-anchored box spec
  function worldBox(f, box) {
    const x = f.facing === 1 ? f.x + box.x - box.w / 2 + 14 : f.x - box.x - box.w / 2 - 14;
    const y = f.y - box.y - box.h;
    return { x, y, w: box.w, h: box.h };
  }

  function hurtbox(f) {
    const crouch = (f.state === 'crouch' || f.blockingLow);
    const h = crouch ? 56 : 96;
    return { x: f.x - FC.PUSH_HALF_W, y: f.y - h, w: FC.PUSH_HALF_W * 2, h };
  }

  function activeHitbox(f) {
    if (f.state !== 'attack' || !f.move) return null;
    const mv = Moves.TABLE[f.move];
    if (f.stateFrame < mv.startup || f.stateFrame >= mv.startup + mv.active) return null;
    return worldBox(f, mv.box);
  }

  // does defender block this height given its current stance?
  function blocks(def, mv) {
    const standingBlock = def.state === 'block' || def.state === 'blockstun';
    const crouchBlock = (def.state === 'crouch' && def.blockingLow);
    if (!standingBlock && !crouchBlock) return false;
    if (mv.height === 'throw') return false;
    if (mv.height === 'low') return crouchBlock;        // lows need crouch block
    if (mv.height === 'overhead') return standingBlock; // overheads need standing block
    return standingBlock || crouchBlock;                // mid/high: either blocks
  }

  function resolve(att, def) {
    const hb = activeHitbox(att);
    if (!hb || att.hitThisMove) return null;
    if (!aabb(hb, hurtbox(def))) return null;
    const mv = Moves.TABLE[att.move];
    att.hitThisMove = true;
    att.meter = Math.min(FC.MAX_METER, att.meter + mv.meterGain);
    if (blocks(def, mv)) {
      Fighter.applyBlock(def, mv, att.x);
      return { type: 'block', move: mv, attacker: att, defender: def };
    }
    Fighter.applyHit(def, mv, att.x);
    att.hitstop = mv.knockdown ? FC.HITSTOP_HEAVY : FC.HITSTOP;
    def.hitstop = att.hitstop;
    def.comboCount = (def.state === 'hitstun') ? def.comboCount : 0;
    return { type: 'hit', move: mv, attacker: att, defender: def };
  }

  function tryThrow(att, def, throwKey) {
    if (!att.onGround || !def.onGround) return null;
    if (def.state === 'hitstun' || def.state === 'knockdown' || def.state === 'attack') return null;
    if (Math.abs(att.x - def.x) > FC.PUSH_HALF_W * 2 + 16) return null;
    const mv = Moves.TABLE[throwKey];
    Fighter.applyHit(def, mv, att.x);
    def.state = 'knockdown'; def.stateFrame = 0;
    def.x = att.x + att.facing * (FC.PUSH_HALF_W * 2); // tossed to attacker's front
    return { type: 'throw', move: mv, attacker: att, defender: def };
  }

  const API = { aabb, worldBox, hurtbox, activeHitbox, blocks, resolve, tryThrow };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.Combat = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
// js/main.js — boot, fixed-timestep loop, wiring.
(function () {
  'use strict';
  const canvas = document.getElementById('game');
  const ctx = canvas.getContext('2d');
  const titleEl = document.getElementById('overlay-title');
  const input = Input.attach(window);

  let scale = 1;
  function resize() {
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = Math.round(window.innerWidth * dpr);
    canvas.height = Math.round(window.innerHeight * dpr);
    canvas.style.width = window.innerWidth + 'px';
    canvas.style.height = window.innerHeight + 'px';
    scale = Math.min(canvas.width / FC.VW, canvas.height / FC.VH);
  }
  window.addEventListener('resize', resize); resize();

  let state = 'title';
  let kate, bungus;
  const kMotion = Input.createMotion();
  let frame = 0;

  function newMatch() {
    kate = Fighter.create('kate', FC.VW / 2 - FC.START_GAP, 1);
    bungus = Fighter.create('bungus', FC.VW / 2 + FC.START_GAP, -1);
    state = 'fight';
    titleEl.classList.add('hidden'); titleEl.setAttribute('aria-hidden', 'true');
  }

  // build the player's intent from held keys + button edges
  let aHeld = 0, sHeld = 0;
  function playerIntent() {
    const dir = Input.dirFromKeys(input.arrows());
    Input.pushDir(kMotion, dir, frame);
    aHeld = input.keys.A ? aHeld + 1 : 0;
    sHeld = input.keys.S ? sHeld + 1 : 0;
    let attack = null;
    // light on press; heavy decided on release-or-hold-threshold (slice: press = light)
    if (input.consumeEdge('A')) attack = { button: 'A', heavy: false, special: null, throw: input.keys.S };
    else if (input.consumeEdge('S')) attack = { button: 'S', heavy: false, special: null, throw: input.keys.A };
    const jump = input.consumeEdge('jump');
    return { dir, jump, attack };
  }

  function applyAttack(f, intent, motion) {
    if (!intent.attack || f.state === 'attack' || f.state === 'hitstun' || f.state === 'knockdown' || f.state === 'blockstun') return;
    const crouch = (intent.dir === 1 || intent.dir === 2 || intent.dir === 3);
    const air = !f.onGround;
    let key;
    if (air) key = intent.attack.button === 'A' ? 'kate.jP' : 'kate.jK';
    else if (crouch) key = intent.attack.button === 'A' ? 'kate.cLP' : 'kate.cLK';
    else key = intent.attack.button === 'A' ? 'kate.LP' : 'kate.LK';
    if (air) { f.move = key; f.state = 'attack'; f.stateFrame = 0; f.hitThisMove = false; }
    else Fighter.start(f, key);
  }

  function sim() {
    frame++;
    const pi = playerIntent();
    // crouch-block flag for combat
    kate.blockingLow = kate.onGround && (pi.dir === 1) ;
    applyAttack(kate, pi, kMotion);
    Fighter.step(kate, pi, bungus);
    Fighter.step(bungus, { dir: 5, jump: false, attack: null }, kate); // dummy
    const ev = Combat.resolve(kate, bungus);
    if (ev) ArtFX.hitSpark(ev);
    Combat.resolve(bungus, kate);
    if (bungus.health <= 0 || kate.health <= 0) state = 'ko';
  }

  let acc = 0, last = 0;
  function frameLoop(t) {
    const dt = Math.min((t - last) / 1000 || 0, 0.1); last = t;
    if (state === 'fight') { acc += dt; let steps = 0; while (acc >= FC.DT && steps < 5) { sim(); acc -= FC.DT; steps++; } }
    render(t);
    requestAnimationFrame(frameLoop);
  }

  function render() {
    ctx.setTransform(1, 0, 0, 1, 0, 0);
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    const ox = (canvas.width - FC.VW * scale) / 2, oy = (canvas.height - FC.VH * scale) / 2;

    }
  }

  window.addEventListener('keydown', (e) => {
    if (e.code === 'Enter' && (state === 'title' || state === 'ko')) newMatch();
  });
  requestAnimationFrame(frameLoop);
})();
```

```js
  function buttonAttack() {
```

```js
// js/specials.js — special-move motion mapping + projectile model. Dual export.
(function (root) {
  'use strict';
  const Input = (typeof module !== 'undefined') ? require('./input.js') : root.Input;
  const Moves = (typeof module !== 'undefined') ? require('./moves.js') : root.Moves;
  const FC = (typeof module !== 'undefined') ? require('./constants.js') : root.FC;

  // priority order: supers first, then specials
  const SPECIALS = [
    { key: 'kate.super', motion: [2,3,6,2,3,6], button: 'A', super: true },
    { key: 'kate.uppercut', motion: [6,2,3], button: 'A' },
    { key: 'kate.fireball', motion: [2,3,6], button: 'A' },
    { key: 'kate.spinkick', motion: [2,1,4], button: 'S' },
  ];

  function detect(ms, button, meterFull, frame, facing) {
    for (const s of SPECIALS) {
      if (s.button !== button) continue;
      if (s.super && !meterFull) continue;
      if (Input.matchMotion(ms, s.motion, frame, FC.BUFFER_FRAMES, facing)) return s.key;
    }
    return null;
  }

  function spawnProjectile(key, from) {
    const mv = Moves.TABLE[key];
    return {
      key, owner: key.split('.')[0], x: from.x, y: from.y,
      vx: from.facing * mv.projSpeed, facing: from.facing,
      life: mv.projLife, life0: mv.projLife, dead: false, hit: false,
    };
  }

  function stepProjectile(p) {
    p.x += p.vx; p.life--;
    if (p.life <= 0 || p.x < FC.STAGE_LEFT - 40 || p.x > FC.STAGE_RIGHT + 40) p.dead = true;
  }

  function projectileBox(p) {
    const mv = Moves.TABLE[p.key];
    return { x: p.x - mv.box.w / 2, y: p.y - mv.box.y - mv.box.h, w: mv.box.w, h: mv.box.h };
  }

  const API = { SPECIALS, detect, spawnProjectile, stepProjectile, projectileBox };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.Specials = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
// js/bungus-ai.js — reactive opponent AI. Pure decision fn. Dual export.
(function (root) {
  'use strict';
  const FC = (typeof module !== 'undefined') ? require('./constants.js') : root.FC;

  // "a notch above easy": reacts, blocks/anti-airs sometimes, presses, throws.
  const DIFFICULTY = {
    reactFrames: 8,        // perception delay
    blockProb: 0.55,       // chance to block a detected incoming attack
    antiAirProb: 0.45,
    aggression: 0.5,       // chance to attack when in range each decision
    specialProb: 0.18,     // chance an in-range attack is a special
    throwProb: 0.12,       // chance to throw a turtling Kate up close
    idleJitter: 0.08,
  };

  function towardDir(b, k, down) {
    const fwd = k.x >= b.x ? 6 : 4;
    return down ? (fwd === 6 ? 3 : 1) : fwd;
  }
  function awayDir(b, k) { return k.x >= b.x ? 4 : 6; }

  function kateAttacking(k) {
    return k.state === 'attack' || k.state === 'jump';
  }

  function decide(b, k, rng, diff, frame) {
    const out = { dir: 5, jump: false, attack: null };
    if (b.state === 'attack' || b.state === 'hitstun' || b.state === 'blockstun' || b.state === 'knockdown') {
      return out; // committed; can't act
    }
    const dist = Math.abs(k.x - b.x);
    const inRange = dist < 86;
    const close = dist < 60;

    // anti-air: Kate jumping in -> sometimes uppercut-equivalent (swipe up) or block
    if (!k.onGround && dist < 120) {
      if (rng() < diff.antiAirProb) { out.attack = { button: 'A', heavy: true }; return out; } // swipe as anti-air
      out.dir = awayDir(b, k); return out;                                                       // else block
    }

    // block incoming grounded attack
    if (kateAttacking(k) && dist < 110 && rng() < diff.blockProb) {
      out.dir = awayDir(b, k) === 6 ? 9 : 7;   // hold up-away? no — hold back; use 4/6 mapped to 1/4 for low cover
      out.dir = (k.x >= b.x) ? 1 : 3;          // crouch-block toward away+down (covers low + most)
      out.dir = (k.x >= b.x) ? 4 : 6;          // standing block away (covers mid/overhead)
      return out;
    }

    if (inRange) {
      // press: attack, throw a turtler, or special
      if (close && rng() < diff.throwProb && (k.state === 'block' || k.state === 'blockstun' || k.state === 'crouch')) {
        out.attack = { throw: true }; return out;
      }
      if (rng() < diff.aggression) {
        if (rng() < diff.specialProb) out.attack = { button: 'A', special: 'bungus.bite' };
        else out.attack = { button: rng() < 0.5 ? 'A' : 'S', heavy: rng() < 0.3 };
        return out;
      }
      // spacing dance
      out.dir = rng() < 0.5 ? awayDir(b, k) : towardDir(b, k, false);
      return out;
    }

    // far: zone with spore sometimes, else approach
    if (dist > 260 && rng() < diff.specialProb) { out.attack = { button: 'A', special: 'bungus.spore' }; return out; }
    if (rng() < diff.idleJitter) { out.dir = 5; return out; }
    out.dir = towardDir(b, k, false);
    return out;
  }

  const API = { DIFFICULTY, decide };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.BungusAI = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
// js/match.js — round/match state machine + timer. Pure. Dual export.
(function (root) {
  'use strict';
  const FC = (typeof module !== 'undefined') ? require('./constants.js') : root.FC;
  const ROUND_START_FRAMES = 90;   // "ROUND n / FIGHT!" banner
  const ROUND_END_FRAMES = 120;    // "K.O." / "TIME" banner

  function create() {
    return {
      phase: 'roundStart', round: 1, wins: { kate: 0, bungus: 0 },
      timer: FC.ROUND_TIME, _t: 0, phaseFrame: 0,
      lastWinner: null, matchWinner: null,
    };
  }

  function endRound(m, winner) {
    m.lastWinner = winner;
    if (winner === 'kate') m.wins.kate++;
    else if (winner === 'bungus') m.wins.bungus++;
    m.phase = 'roundEnd'; m.phaseFrame = 0;
  }

  function step(m, kateHP, bungusHP) {
    m.phaseFrame++;
    if (m.phase === 'roundStart') {
      if (m.phaseFrame >= ROUND_START_FRAMES) { m.phase = 'fight'; m.phaseFrame = 0; m.timer = FC.ROUND_TIME; m._t = 0; }
      return;
    }
    if (m.phase === 'fight') {
      m._t += FC.DT;
      if (m._t >= 1) { m._t -= 1; m.timer = Math.max(0, m.timer - 1); }
      if (kateHP <= 0 && bungusHP <= 0) return endRound(m, 'draw');
      if (bungusHP <= 0) return endRound(m, 'kate');
      if (kateHP <= 0) return endRound(m, 'bungus');
      if (m.timer <= 0) {
        if (kateHP > bungusHP) return endRound(m, 'kate');
        if (bungusHP > kateHP) return endRound(m, 'bungus');
        return endRound(m, 'draw');
      }
      return;
    }
    if (m.phase === 'roundEnd') {
      if (m.wins.kate >= FC.ROUNDS_TO_WIN) { m.phase = 'matchEnd'; m.matchWinner = 'kate'; return; }
      if (m.wins.bungus >= FC.ROUNDS_TO_WIN) { m.phase = 'matchEnd'; m.matchWinner = 'bungus'; return; }
      if (m.phaseFrame >= ROUND_END_FRAMES) {
        m.round++; m.phase = 'roundStart'; m.phaseFrame = 0;
      }
      return;
    }
    // matchEnd: terminal
  }

  const API = { create, step, ROUND_START_FRAMES, ROUND_END_FRAMES };
  if (typeof module !== 'undefined' && module.exports) module.exports = API;
  else root.Match = API;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
  'use strict';
  const TEMPO=140, STEP=60/TEMPO/4, BAR=16, MUSIC=0.55;
  // A minor vibe: i - VI - VII - i  (A C D A roots), tense
  const ROOTS=[110.00, 87.31, 98.00, 110.00];     // A2 F2 G2 A2
  const STAB=[[220,261.63,329.63],[174.61,220,261.63],[196,246.94,293.66],[220,261.63,329.63]];
  let ctx=null,master,musicBus,sfxBus,noise,muted=false,on=false,timer=null,step=0,nextT=0;

  function ensure(){ if(ctx) return; const AC=root.AudioContext||root.webkitAudioContext; if(!AC) return;
    ctx=new AC(); master=ctx.createGain(); master.gain.value=muted?0:1; master.connect(ctx.destination);
    musicBus=ctx.createGain(); musicBus.gain.value=MUSIC; musicBus.connect(master);
    sfxBus=ctx.createGain(); sfxBus.gain.value=0.9; sfxBus.connect(master);
    noise=ctx.createBuffer(1,ctx.sampleRate,ctx.sampleRate); const d=noise.getChannelData(0);

  }

  };
```

```markdown
# Kate vs. Bungus (k8fighter)

A Street Fighter-style 1v1. Play Kate against **Bungus**, an oozing fungal
death-rabbit. Best of 3 rounds. Everything — art, music, voice — is generated
live in the browser; there are no asset files.

## Play

Open `index.html` in any modern browser (or serve the folder with any static
server). **Enter** to fight. **Arrows** move, **↓** crouch, **↑/Space** jump,
**A** punch, **S** kick (tap = light, hold = heavy). Hold **away** to block
(crouch-block lows). **A+S** to throw. **H** shows the move list. Mute is
bottom-right.

Specials (Kate, facing right): Fireball ↓↘→ + A · Uppercut →↓↘ + A ·
Spin Kick ↓↙← + S · Super ↓↘→↓↘→ + A (full meter).

## Layout

- `js/constants.js` — tuning constants
- `js/input.js` — keys + motion detection (`node tests/input.test.js`)
- `js/moves.js` — frame data for every move
- `js/moveselect.js` — intent → move key (`node tests/moveselect.test.js`)
- `js/fighter.js` — physics + state machine (`node tests/fighter.test.js`)
- `js/combat.js` — hit/block/throw resolution (`node tests/combat.test.js`)
- `js/specials.js` — special motions + projectiles (`node tests/specials.test.js`)
- `js/bungus-ai.js` — opponent AI (`node tests/bungus-ai.test.js`)
- `js/match.js` — rounds/timer (`node tests/match.test.js`)
- `js/art-*.js` — Kate, Bungus, stages, FX/HUD rendering
- `js/audio.js`, `js/voice.js` — music/SFX and taunts
- `js/main.js` — fixed-timestep loop + wiring

Run all logic tests: `for f in tests/*.test.js; do node "$f"; done`
```

## Self-review notes (for the executor)

- **Type/name consistency:** the fighter, move, intent, and event shapes in the
  "Shared conventions" section are authoritative; every task uses those exact
  field names (`hitThisMove`, `blockingLow`, `stateFrame`, `move.box`, event
  `{type,move,attacker,defender}`).
- **`blockingLow`** is set by the orchestrator (`main.js`) from input each frame
  (down + away while grounded) and read by `combat.js`. Bungus's `blockingLow`
  is set by `main.js` from the AI intent the same way.
- **Projectiles** live in `main.js` as a list; `specials.js` provides the model
  and `combat.js` the `applyProjectileHit` resolver.
- **Audio/Voice** are optional at every call site (guarded by `window.Audio` /
  `window.Voice`) so earlier milestones run before they exist.
- Each milestone leaves the game runnable; commit after every task.
